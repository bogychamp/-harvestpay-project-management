# HarvestPay: Project Management & System Architecture

This repository contains the project management documentation, system architecture, and planning artifacts for **HarvestPay** — a conceptual hardware-to-cloud solution designed to optimize harvest tracking for wineries.

*Developed as part of the "Project Management of Information Systems" course during the Erasmus+ exchange program at the University of Maribor.*

---

## 📌 Project Overview
Traditional harvest tracking relies heavily on manual paper-based entry and delayed reporting. HarvestPay proposes a contactless ecosystem utilizing **NFC Wristbands** for field workers and **NFC-compatible smartphones** for supervisors, streaming real-time data directly to a cloud-based dashboard for Winery Managers and Owners.

## ⚙️ Project Management & Planning
The primary focus of this project was mastering project management methodologies using **ProjectLibre**:

* **Work Breakdown Structure (WBS):** Detailed mapping of project phases, from initiation and customer kick-off to planning, integration, and final deployment.
* **Resource Allocation:** Structuring cross-functional team roles (Project Manager, NFC Integration Developers, Backend Developers, QA Testers) and configuring hardware/cloud infrastructure resources.
* **Scheduling & Calendars:** Managing task dependencies, establishing project baselines, and setting custom working calendars ("Пятидневка").
