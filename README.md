# HarvestPay: Project Management & System Architecture

This repository contains the project management documentation, system architecture, and planning artifacts for **HarvestPay** — a conceptual hardware-to-cloud solution designed to optimize harvest tracking for wineries.

*Developed as part of the "Project Management of Information Systems" course during my Erasmus+ exchange at the University of Maribor.*

## 📌 Project Overview
Traditional harvest tracking relies heavily on manual paper-based entry. HarvestPay proposes a contactless ecosystem utilizing **NFC Wristbands** for field workers and **NFC-compatible smartphones** for supervisors, streaming real-time data to a cloud-based dashboard for Winery Managers and Owners.

## ⚙️ Project Management & Planning
The primary focus of this course project was mastering project management methodology using **ProjectLibre**:
* **Work Breakdown Structure (WBS):** Detailed mapping of project phases from customer kick-off through initiation, planning, and deployment.
* **Resource Allocation:** Structuring team roles (Project Manager, Developers, QA) and hardware/cloud resources within ProjectLibre.
* **Scheduling & Calendars:** Managing task dependencies, project baselines, and custom working calendars ("Пятидневка").
